# Source provenance

The initial theme sources were extracted from the committed `themes/` directory
of [sailry/sailry-harness](https://github.com/sailry/sailry-harness/tree/ea76c95e4dc40e5c3b7a279dd082f6eccc151cfd/themes)
at commit `ea76c95e4dc40e5c3b7a279dd082f6eccc151cfd`.

The three packages are `great-sage`, `ink-dragon` and `holographic-rhythm`.
All existing artwork bytes, generation prompts and license texts are preserved.
Only their unreleased `package_version` fields are normalized to `0.1.0`.
Repository documentation adds independent maintenance and catalog commands.

Each package's `ARTWORK.md` retains its individual references, generation prompts
and licensing. This repository does not contain the Sailry application, GPUI Kit
or another copy of the native theme implementation.
